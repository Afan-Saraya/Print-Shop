Test Navigacije - Saraya Print Shop

🚨 Problem

Kada pokušavate da pređete sa home stranice na personalize stranicu, URL se menja ali stranica se ne učitava.

✅ Rešenje

Identifikovao sam i popravio sledeće probleme:

  • window.location.href - Zamenio sa Next.js router.push() za pravilno client-side rutiranje
  • GlobalLoader - Modifikovao da ne blokira navigaciju između stranica
  • Editor refresh - Zamenio window.location.href sa router.replace()

if (fromCategory === 'true' && typeof window !== 'undefined') {
  const newUrl = `/editor?model=${encodeURIComponent(model || '/cap/scene.gltf')}`;
  window.location.href = newUrl;
}

// NOVO (ispravno)
if (fromCategory === 'true' && typeof window !== 'undefined') {
  const newUrl = `/editor?model=${encodeURIComponent(model || '/cap/scene.gltf')}`;
  router.replace(newUrl, undefined, { shallow: true });
